Netflix Investimento: Plataforma de Investimento Integrada

Sobre o Projeto

Plataforma de investimento com banco de dados funcional e integracoes com APIs bancarias, Pix, cartao e gateway de pagamento. Inclui painel admin para controle de operacoes, conciliacao e monitoramento de transacoes.

Detalhes do Projeto

  • Tipo: Plataforma de Investimento com Integracoes Bancarias
  • Objetivo: Operacoes financeiras integradas com painel administrativo
  • Funcionalidades:
    • Cadastro e onboarding de usuarios
    • Gestao de carteira e saldos
    • Integracao com APIs de bancos, Pix e cartao
    • Gateway de pagamento integrado
    • Painel admin para controle de operacoes
    • Conciliacao e monitoramento de transacoes

Tecnologias Utilizadas

HTML5 CSS3 JavaScript API Banco de Dados Banco de Dados Schema via SupaBase Pix Cartao Gateway de Pagamento
